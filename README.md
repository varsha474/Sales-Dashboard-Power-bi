 SALES DASHBOARD USING POWER BI
 Sales Dashboard | Power BI

 Project Overview

This project presents an interactive Sales Dashboard built using Microsoft Power BI to analyze revenue, quantity, orders, regional performance, monthly revenue trends, and category-wise revenue distribution.

 Project Objectives

- Monitor overall sales performance.
- Analyze quantity by region.
- Track monthly revenue trends.
- Compare revenue across product categories.
- Present key business metrics in a clear visual format.

 Tools Used

- Microsoft Power BI
- Data Visualization
- Sales Data Analysis

 Dashboard Highlights

The dashboard includes the following visualizations:

- Total Revenue: $40.52M
- Total Quantity: 7K
- Total Orders: 5K
- Quantity by Region: Compares quantity across regions.
- Monthly Revenue Trend: Shows how revenue changes over time.
- Revenue by Category: Displays the revenue distribution across product categories.

 Key Insights

- The dashboard provides a quick overview of total revenue, quantity, and orders.
- Regional analysis helps compare sales quantity across different regions.
- Monthly revenue trends help identify changes in sales performance.
- Category-wise analysis helps compare revenue contribution across product categories

Conclusion
This project demonstrates the use of Power BI to transform sales data into interactive visualizations and meaningful business insights.
